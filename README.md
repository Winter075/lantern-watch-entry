Lantern Watch is an original spot-the-difference game with four procedurally drawn night scenes, eight changes per scene, keyboard and mouse controls, hint and magnifier tools, generated chimes, and a gentle timer. All art and audio are made by the game's own code; there are no external assets or network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
